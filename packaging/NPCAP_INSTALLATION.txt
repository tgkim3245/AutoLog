Npcap setup through Initial_Setup.bat / 초기설정 BAT 안내 / 初始设置 BAT 说明

한국어
1. 배포 ZIP 전체를 로컬 폴더에 압축 해제합니다. 앱과 모든 CANoe 작업을 저장·종료합니다.
2. EXE 옆 Initial_Setup.bat를 더블클릭하고 사용할 CANoe 설치본의 목록 번호를 입력합니다.
3. BAT가 Npcap 기설치 상태를 확인합니다. 있으면 건너뛰고, 없으면 이 폴더의 공식 설치 파일을 검증해 관리자 권한으로 자동 실행합니다.
4. Windows 관리자 요청을 승인하고 BAT가 연 공식 설치창에서 라이선스·옵션을 확인해 설치를 완료합니다. 무인 설치가 아니며 동의·확인은 사용자가 합니다.
5. 재부팅을 요청하면 재부팅한 뒤 BAT를 다시 실행해 확인합니다. Zipy를 사용하려면 결과 Npcap: 0을 확인합니다.
6. 앱을 다시 실행하고 설정 → Ethernet 연결에서 네트워크 선택·연결 확인을 진행합니다.
7. 이 동봉본은 확인된 같은 회사 내부 PC 1대용입니다. 빌드 중 설치기를 실행하거나 현재 PC 드라이버를 변경하지 않습니다. 외부 배포물로 전용하지 마세요. LICENSE.txt 및 공식 설치창의 약관이 적용됩니다.
예외: BAT가 설치 파일 누락을 알리면 먼저 ZIP 전체를 압축 해제했는지 확인합니다. 설치기를 포함하지 않는 일반 배포본은 PC 관리자 또는 공식 사이트를 통해 준비합니다.

English
1. Extract the complete distribution ZIP. Save and close the app and all CANoe windows.
2. Double-click Initial_Setup.bat beside the EXE and enter the list number for the CANoe installation to use.
3. If Npcap is already installed, the BAT skips it; otherwise it verifies and automatically launches this folder's official installer as administrator.
4. Approve Windows elevation and review/accept the license and options in the official installer opened by the BAT. This is interactive; the user completes these dialogs.
5. If a restart is requested, restart and run the BAT again. Confirm Npcap: 0 for Zipy.
6. Reopen the app, choose the network under Settings > Ethernet connection and check the connection.
This installer is bundled for the confirmed single PC inside the same company. The build does not execute it or change drivers. Do not repurpose this internal package for external distribution. LICENSE.txt and official installer terms apply.
Exception: if the BAT reports a missing installer, first verify full ZIP extraction. A standard package without an installer requires preparation through your PC administrator or the official site.

中文
1. 完整解压发行包 ZIP。保存工作并关闭应用和所有 CANoe 窗口。
2. 双击 EXE 旁的 Initial_Setup.bat，输入要使用的 CANoe 安装版本的列表编号。
3. BAT 跳过已有的 Npcap，缺少时验证并自动以管理员身份启动本文件夹中的官方安装程序。
4. 批准 Windows 提权，在 BAT 打开的官方安装界面阅读并同意许可证/选项，完成安装。此过程需要交互，由用户完成同意和确认。
5. 如要求重启，请重启后再次运行 BAT。使用 Zipy 时请确认 Npcap: 0。
6. 重新打开应用，在设置 > Ethernet 连接中选择网卡并检查连接。
此安装文件仅随已确认的同一公司内部单 PC 发行包附带。构建过程不会运行安装程序或修改驱动。请勿用于外部分发。适用条件见 LICENSE.txt 及官方安装界面。
例外：若 BAT 提示缺少安装文件，请先确认 ZIP 已完整解压。不含安装程序的普通发行包需通过 PC 管理员或官方网站准备。
