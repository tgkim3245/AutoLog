Npcap - same-company internal PC setup / 사내 PC 설치 / 公司内部电脑安装

한국어
1. 이 배포본은 요청한 같은 회사 내부 PC 1대용입니다.
2. 대상 PC에 Npcap이 이미 설치돼 있으면 다시 설치할 필요가 없습니다.
3. 처음 설치하는 PC에서는 One Click Log를 닫고, 이 폴더의 npcap-1.90.exe를
   우클릭 → 관리자 권한으로 실행하세요. 공식 설치창에서 라이선스를 읽고
   동의한 뒤 기본 옵션으로 설치를 완료하세요. 설치/권한 승인은 사용자가 합니다.
4. 설치 후 One Click Log를 다시 실행 → 설정 → Ethernet 연결 → 네트워크 선택
   → 연결 확인 순서로 준비하세요. 설치 프로그램이 재부팅을 요청하면 먼저 완료하세요.
5. 설치 파일 동봉만으로 드라이버가 설치되지는 않습니다. 빌드 중 드라이버를
   설치하거나 현재 PC의 드라이버를 변경하지 않았습니다.
6. 무료 사용 대수와 외부 재배포 권한은 별개입니다. 외부 배포물로 전용하지 마세요.
   다른 사용 범위는 아래 공식 조건을 확인하세요. LICENSE.txt 및 설치창의 약관이 적용됩니다.

English
This package was prepared for the requested single PC inside the same company.
If Npcap is already installed, no reinstallation is needed. Otherwise, close
One Click Log, right-click npcap-1.90.exe and choose Run as administrator.
Read and accept the license in the official installer and complete installation
with default options. The user handles installation and permission prompts.
Reboot first if requested. Reopen One Click Log, choose the adapter under
Settings > Ethernet connection and check the connection.
The bundled file does not install itself. No driver was installed by the build.
Free installation limits do not grant external redistribution rights. Do not
repurpose this internal package for external distribution; see the official terms.
