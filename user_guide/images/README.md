# 안내용 실제 UI 화면

현재 앱의 Qt 위젯을 `../capture_screenshots.py`로 촬영한다. 경로·연결·수신량·완료 상태는 설명용 예시이며 실제 장비 취득 성공을 나타내지 않는다. 실제 사용자 cfg나 캡처, 시리얼 번호, 개인 경로를 넣지 않는다.

화면이 바뀌면 재촬영하고 12장 전체를 확인한다. `manifest.json`은 촬영 시 앱 버전·크기·SHA256을 기록한다. 가이드 본문의 이미지 자리표시는 렌더 때 PNG data URL로 포함되므로 배포 HTML은 단독으로 열 수 있다. PNG 원본과 manifest는 Git에서 추적한다.
