1. ZIP 전체를 쓰기 가능한 로컬 폴더에 압축 해제한 뒤 AutoLog.exe를 실행하세요.
   EXE와 _internal 폴더를 함께 유지하세요. 사용자 PC에 Python/Git 설치는 필요 없습니다.
   현재는 시험용 배포입니다. 사용하는 PC·cfg·장비에서 짧은 기록부터 확인하세요.

2. CAN/Diag 준비: CANoe, 필요한 버스 옵션 라이선스, Vector 장비·드라이버,
   .cfg와 참조 파일을 준비하세요. Zipy는 Wireshark(TShark/dumpcap/capinfos)와
   Npcap을 준비하세요. 설치는 별도 설치 안내를 따릅니다.

3. 중요 — Windows Defender 허용 앱
   CAPL 컴파일에서 '.cbf: 액세스가 거부되었습니다'가 나오면 다음을 확인하세요.
   Windows 보안 → 바이러스 및 위협 방지 → 랜섬웨어 방지 관리
   → 제어된 폴더 액세스를 통해 앱 허용 → 허용된 앱 추가

   C:\Program Files\Vector CANoe 19\Exec64\CAPLcompExec.exe
   C:\Program Files\Vector CANoe 19\Exec64\CANoe64.exe

   위 경로는 CANoe 19의 기본 설치 예시입니다. 실제 설치된 Vector 파일을 지정하세요.
   회사 정책으로 변경할 수 없으면 PC 관리자에게 이 두 파일의 허용을 요청하세요.
   보호 기능 전체를 끌 필요는 없습니다. 허용 후 CANoe를 완전히 재시작하고
   Diag를 재컴파일한 뒤 측정·수동 기록부터 확인하세요.

4. CAN/Diag: cfg 선택·연결 확인 → 전용 CANoe 창에서 컴파일/채널·라이선스 확인
   → F9 측정·Trace 수신 확인 → 메인의 기록 시작/정지. 연결 재확인은 필수가 아닙니다.
   측정을 켜둔 채 기록 시작·정지·다음 기록을 반복하며, 시작 때 측정 상태를 자동 확인합니다.
   CAN과 Diag는 서로 다른 cfg를 각각 별도 CANoe 창에서 사용합니다.
   먼저 수동 기록을 시험했다면 해당 기록만 정지하고 F9 측정은 유지하세요.
   같은 블록에서 BLF 파일명만 바뀐 경우 연결을 다시 하지 않고 기록 시작을 누르면 됩니다.
   CANoe의 수동 Logging 패널과 AutoLog를 함께 조작하지 마세요.

5. Zipy: tshark.exe 직접 선택 → 장비에 연결된 네트워크 선택·연결 확인
   → 저장 위치·파일 prefix·다음 인덱스 확인 → 메인 대상 선택 → 기록 시작/정지.
   메인 버튼은 상태에 따라 문구와 색이 바뀝니다. 준비/시작 중에는 취소,
   기록 중에는 정지, 완료 후에는 다음 기록 시작입니다. 파일 정리 중에는 기다려 주세요.

6. 종료 후 파일 보관 결과를 확인하세요. 문제 발생 시 '버그리포트'를 눌러
   바탕화면에 생성된 ZIP과 발생 시각/조작 순서를 Taegon.Kim에게 이메일로 보내 주세요.
   앱이 이메일을 자동 전송하지는 않습니다.
   CAN/Diag는 기록 정지 뒤 이번 BLF의 마지막 버퍼·헤더를 완성해 보관합니다.
   다음 trigger가 필요한 경우 별도 내부 파일로 짧게 전환해 마무리하며 측정은 유지합니다.
   .vil_work는 기록 중·마무리 중 파일용 작업 폴더이며 완성된 사용자 로그는 저장 폴더에 보관합니다.
   잠긴 내부 파일은 핸들 해제 후 소유·보관 근거를 확인해 자동 정리합니다.
   '기존 출력 경로 복구 보류'는 cfg의 이전 이름을 CANoe가 거부한 경우입니다.
   0.9.9부터 정지한 AutoLog 소유 블록이 확인되면 다음 기록을 계속할 수 있습니다.
   최종 BLF 검사·보관은 유지하며, 보류된 임시 출력 경로를 cfg에 저장하지 마세요.
   '정지·보관 확인 필요'는 파일이 없다는 뜻이 아닙니다. 복구 화면에서 원인을 확인하고
   계속 실패하면 임시 파일을 보존한 채 버그리포트를 보내 주세요.
   메인 X는 언제든 종료합니다. 정리 실패 또는 약 3초 초과 시 강제 종료하며,
   X를 다시 누르면 즉시 강제 종료합니다. 미완료 파일·이력·번호는 유지합니다.
   강제 종료 파일은 완결되지 않을 수 있으니 다음 실행에서 미완료 확인을 사용하세요.
   외부 CANoe 창·측정은 유지됩니다. 남아 있는 기록은 CANoe에서 먼저 정지·확인하세요.
