# 성과 기록

아직 실측 결과가 없다. 아래 표는 측정 양식이며 개선 효과를 의미하지 않는다.

## 1. 비교 조건

- 같은 시험 PC·도구 버전·장비·시험 설정과 가능한 한 같은 작업 조건을 사용한다.
- 수동 작업과 통합 패널 작업의 시작·종료 기준을 동일하게 정의한다.
- 반복 횟수와 조건 차이를 함께 기록한다. 평균·중앙값·범위는 실제 표본을 확보한 뒤 계산한다.
- 시험 PC별 성능 차이, 장비 연결 시간, 파일 검증 시간의 포함 여부를 남긴다.

## 2. 지표 정의와 기록

| 지표 | 측정 방법 | 수동 작업 | 통합 패널 | 근거 |
| --- | --- | --- | --- | --- |
| 취득 준비 시간 | 정한 준비 시작 시점부터 두 로그가 실제 기록 중임을 확인할 때까지 | 미측정 | 미측정 | 시간 측정·이벤트 |
| 수동 조작 수 | 같은 작업 범위의 버튼 클릭·입력·창 전환 수, 범위를 명시 | 미측정 | 미측정 | 작업 순서·녹화 |
| 유효 로그 쌍 확보율 | 두 파일 모두 열리고 필요한 취득 범위를 포함한 세션 수 / 전체 시도 수 | 미측정 | 미측정 | 파일 검증 기록 |
| 이상 감지 지연 | 정의된 이상 기준 발생 시각부터 패널 경고까지, 시간 기준·불확실성 명시 | 미측정 | 미측정 | 주입·패널 이벤트 |
| 오경보 | 정상 조건에서 발생한 경고 수와 관측 시간 또는 세션 수 | 미측정 | 미측정 | 정상 시험 결과 |
| 재시험 | 로그 취득 문제로 다시 수행한 횟수와 전체 시험 수 | 미측정 | 미측정 | 재시험 사유 기록 |

시간 절감률은 `(수동 작업 시간 - 통합 패널 작업 시간) / 수동 작업 시간 × 100`으로 계산한다. 수동 작업 시간이 0이거나 비교 조건이 맞지 않으면 계산하지 않는다.

절감 시간을 비용으로 환산할 경우 인건비·횟수·사용 기간 등의 근거와 가정을 함께 적는다. 예상 효과와 실측 효과는 구분한다.

## 3. 증거 목록

| 증거 | 권장 위치 | 기록할 내용 |
| --- | --- | --- |
| 기존 작업 흐름 | `evidence/before/` | 실제 단계·조작 수·측정 조건 |
| 통합 패널 화면 | `evidence/after/` | 도구별 취득·통신 상태가 보이는 화면 |
| 로그 취득 결과 | 검증 세션 경로를 참조 | PCAP·BLF 읽기와 취득 범위 확인 |
| 이상 검출 사례 | `evidence/fault-cases/` | 조건, 실제 증상, 패널 표시, 복구 |
| 성과 측정 | `evidence/measurements/` | 원시 측정값·횟수·계산 방식 |

차량 식별 정보·주소·사내 프로젝트명·민감한 패킷 내용 등은 공유 범위에 맞게 가린다. PPT에는 설명에 필요한 근거만 사용한다.
