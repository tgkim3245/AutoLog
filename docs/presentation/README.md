# 발표와 성과 측정 자료

발표의 구성과 측정 양식을 배포용 사용자 가이드와 분리해 관리한다. 이 폴더는 발표 제작/개정 시 참고하는 문서이며 실제 배포 가이드에 포함하지 않는다.

- [발표 구성](outline.md): 배경·문제·구현·검증·효과·남은 과제의 설명 순서.
- [성과 기록 양식](performance_notes.md): 비교 조건·원시 측정·반복 횟수·계산 기준.

제품 동작과 실제 검증 범위는 [현재 구현 상태](../reference/implementation_status.md)를 먼저 확인한다. localhost/대역 검증·과거 현장 확인·현재 버전 실차 확인을 섞지 않는다. 슬라이드와 원본 증빙은 로컬 산출물로 별도 관리하고 개인/차량/업무 데이터는 Git에 넣지 않는다.
