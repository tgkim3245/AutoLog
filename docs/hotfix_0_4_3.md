# 0.4.3 — 상시 개발자 로그와 버그리포트

2026-10-18 · VIL Logging 0.4.3

[실행 파일](../outputs/hotfix-0.4.3/VILLogging/VILLogging.exe). 실행 파일과 같은 폴더의 `_internal` 디렉터리도 함께 유지한다.

## 변경 사항

- 최근 활동 목록과 앱 시작 시 읽어 오는 저장 이력을 최대 500개로 늘렸다.
- 개발자 진단 로그를 앱 시작부터 종료까지 상시 저장한다. `%LOCALAPPDATA%\VILLogging\developer_logs\developer.jsonl`에 5MB 단위로 기록하고 최대 4개 백업 파일을 순환 보관해 크기를 제한한다.
- 상단의 `개발자로그` 체크박스를 `버그리포트` 버튼으로 교체했다. 누르면 현재 로그와 순환 백업을 ZIP으로 묶어 바탕화면에 저장하고 `Taegon.Kim`에게 이메일로 보내 달라는 안내를 표시한다. 메일은 앱에서 직접 보내지 않는다.
- 기존 진단 로그의 패킷·프레임 원문과 바이트 데이터 마스킹은 유지한다.

## 검증

- 자동 테스트 206개 통과, Ruff 통과.
- 앱 버튼 통합 검사에서 바탕화면 ZIP 생성, 파일명 표시, 이메일 안내 및 ZIP 안의 최신 내보내기 이벤트를 확인했다.
- 배포 EXE 모의 실행에서 상시 저장된 54개 JSONL 기록과 녹화 시작·완료 이벤트를 확인했다. 빌드 정보는 [build_info.json](../outputs/hotfix-0.4.3/VILLogging/build_info.json)에 기록했다.
- 시험 PC의 차량 NIC, CANoe, 고속 부하 및 장시간 수집은 별도 검증이 필요하다.
