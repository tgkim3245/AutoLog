# 사진으로 따라 하는 사용법 — 0.9.18

2026-10-23. 메인 버그리포트 왼쪽에 사용법 버튼을 추가했다. 한국어·영어·중국어 표시는 사용법 / Guide / 使用说明이다. 기록·정리 중에도 사용할 수 있고, 기본 브라우저에서 EXE 옆의 `One Click Log_User_Guide.html`을 연다. 현재 작업 디렉터리에 의존하지 않는다. 파일이나 브라우저 연결을 사용할 수 없으면 전체 ZIP 압축 해제와 직접 HTML 열기를 안내하며 개발자 로그에 원문을 남긴다.

기존 상세 가이드를 삭제하지 않고 접어 두고, 첫 화면을 저장 위치 → CAN·Diag 연결 → Zipy 연결 → 기록 시작/정지 → 파일 확인의 5단계로 정리했다. 사용하는 대상의 연결만 따라갈 수 있다. 현재 Qt 위젯으로 만든 예시 사진 12장을 배치하고, 클릭 확대·Esc/닫기와 상세 항목 링크 자동 펼침을 추가했다. 경로·연결·수신량은 설명용이며 실제 사용자 cfg·캡처·개인 경로를 포함하지 않는다.

PNG는 렌더 때 HTML에 data URL로 포함한다. 인터넷·별도 서버가 필요 없고 사진 폴더를 따로 복사하지 않아도 기본 브라우저에서 읽을 수 있다. 빌드와 소스 실행이 같은 렌더러를 사용한다. 사진·원본·문서 개정·안내문을 함께 추적하고 파일 누락/잘못된 PNG/검토 버전 불일치는 배포 생성 전에 차단한다. 가이드 개정은 `2026-10-23.5`다.
