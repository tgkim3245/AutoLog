# 시험 PC별 설정과 환경 확인

이 문서는 시험 PC에서 확인할 설정·장비 항목의 참고표다. 앱은 사용자가 지정한 캡처 도구 경로, NIC, 파일 형식과 저장 옵션을 사용자별 SQLite 설정에 저장한다. 이 문서는 앱이 읽는 설정 파일이 아니다.

PC별 CANoe `.cfg`, 실제 경로, 장치 정보, 자격 증명과 캡처 결과를 이 디렉터리에 추가하지 않는다. 공유 가능한 비밀 없는 예시가 필요하면 실제 값과 경로를 제거한 샘플만 별도로 둔다.

## 새 PC에서 시작하기

1. 배포 ZIP 전체를 쓰기 가능한 폴더에 풀고 `AutoLog.exe`를 실행한다. `_internal/`을 함께 유지하며 Python을 따로 설치할 필요는 없다.
2. 필요한 도구가 없으면 환경 확인창이 열린다. 설치는 별도 PPT/회사 안내에 따라 진행하며 앱에는 설치 링크·설치 실행·복구 버튼이 없다. 오프라인 PC는 회사 승인 설치파일을 미리 준비한다.
3. Wireshark의 TShark·Npcap을 준비한 뒤 **설정 → Ethernet 연결 → 직접 선택**에서 `tshark.exe`를 지정한다. 경로는 기억되며 자동으로 다른 설치본을 고르지 않는다. 환경 확인의 **설치·설정 후 다시 확인**으로 설치 상태를 재확인한다.
4. Ethernet 네트워크 목록의 수신 그래프·네트워크 이름을 참고해 차량 장비가 연결된 네트워크를 선택하고 연결을 확인한다. 그래프는 전체 어댑터 수신량이며 캡처 성공을 뜻하지 않는다. 저장 폴더도 지정한다. CAN/Diag는 각각 .cfg를 선택하고 독립 CANoe 창에서 측정을 준비한다. [자동 독립 연결](canoe_independent_connection.md)과 [라이선스 CANoe 시험](licensed_canoe_validation.md)을 따른다.

현재 검증 범위는 [0.8.6 전체 검토](project_audit_0_8_6.md)를 따른다. 과거 0.4.6의 앱 내 설치·복구 안내는 현재 UI에 적용하지 않는다.

아직 기준이 없는 감시는 설정 필요, 정보 접근 불가는 확인 불가/미지원으로 유지한다. 값 고정·패킷 0개·프로세스 생존만으로 통신 상태를 단정하지 않는다.

실제 원본 구성은 의존 파일을 포함한 경로 관계를 유지한다. 공통 앱 배포 때 업무 .cfg·데이터베이스·로그·라이선스 자료를 자동 복사하지 않는다.

자료의 확인 순서와 설치 항목은 [착수 전 검토](development_readiness_review.md), [설치 목록](installation_matrix.md), [개발·배포 계획](development_delivery_plan.md)을 따른다.
