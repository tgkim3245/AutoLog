# 시험 PC별 설정과 환경 확인

이 문서는 시험 PC에서 확인할 설정·장비 항목의 참고표다. 앱은 사용자가 지정한 캡처 도구 경로, NIC, 파일 형식과 저장 옵션을 사용자별 SQLite 설정에 저장한다. 이 문서는 앱이 읽는 설정 파일이 아니다.

PC별 CANoe `.cfg`, 실제 경로, 장치 정보, 자격 증명과 캡처 결과를 이 디렉터리에 추가하지 않는다. 공유 가능한 비밀 없는 예시가 필요하면 실제 값과 경로를 제거한 샘플만 별도로 둔다.

| 구분 | 현재 확인 | PC별로 확인·설정할 항목 |
| --- | --- | --- |
| OS | Windows 11 64비트 | 실제 Windows 빌드·배포물 실행 결과 |
| CANoe | 19, VN 장비 인증 | 실행 경로·에디션·SP·빌드·독립 COM 참조 |
| CAN | 슬롯 1의 BLF 취득 | .cfg 전체 경로·대상 Logging Block·기존 구간/후행 기록 |
| Diag | 슬롯 2의 BLF 취득 | .cfg 전체 경로·대상 블록·슬롯 1과 제어/채널 대응 |
| VN 장비 | 여러 장비 사용 | 정확한 모델·채널·드라이버·기대/확인된 매핑 |
| Zipy/Ethernet | NIC 한 개·TShark 우선안 | 도구 경로·버전·Npcap 상태·NIC 식별자/설명·선택 형식 |
| 저장 | 로컬 디스크 | 폴더·파일 시스템·쓰기/남은 공간·임시/최종 경로 |
| 이름 | prefix와 인덱스 | CAN=prefix+번호, Diag=prefix+Diag_+번호, Ethernet=prefix+번호 |
| 번호/이력 | PC/사용자별 독립 보존 | 저장소 위치·스키마 버전·다음 번호·미완료 세션 |
| 구간·용량 | 약 1분, 30분 초과, 1GB 초과 가능 | 실제 최장 구간·대표 기록 속도·최대 파일·장시간 검증 |
| CAN 감시 | 로깅 중만, 기준 추후 | 읽을 수 있는 수신 근거·대상·주기·미수신/유예/복귀 조건 |
| Ethernet 감시 | 로깅 중만, 기준 추후 | 대상 흐름·IP/MAC·주기·미수신/유예/복귀 조건 |
| 원본 보존 | 기존 .cfg 유지 선호 | 코드/변수 자동 추가·저장 없음. 복사본 보조안은 필요할 때 별도 검토 |
| 실행 시간 제한 | 제어 정책의 초기값 | 도구별 실제 시작·정지·후행 기록·파일 검사 소요 |
| 배포 | 팀 PC·오프라인 앱 실행 | 앱/의존성 버전·해시·지원 외부 도구 조합·PC별 설치 확인 |

아직 기준이 없는 감시는 설정 필요, 정보 접근 불가는 확인 불가/미지원으로 유지한다. 값 고정·패킷 0개·프로세스 생존만으로 통신 상태를 단정하지 않는다.

실제 원본 구성은 의존 파일을 포함한 경로 관계를 유지한다. 공통 앱 배포 때 업무 .cfg·데이터베이스·로그·라이선스 자료를 자동 복사하지 않는다.

자료의 확인 순서와 설치 항목은 [착수 전 검토](development_readiness_review.md), [설치 목록](installation_matrix.md), [개발·배포 계획](development_delivery_plan.md)을 따른다.
