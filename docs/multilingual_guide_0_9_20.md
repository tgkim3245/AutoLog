# 다국어 사용가이드 — 0.9.20

사용법 HTML 상단의 **한국어 / English / 中文**으로 빠른 시작·접힌 상세·오류/보안/제한 안내·사진·접근성 설명을 함께 전환한다. 중국어는 간체다. 사진은 언어별 실제 Qt 위젯에 설명용 데이터만 넣어 촬영했으며 장비/COM/Runtime에 연결하지 않았다. 저장된 사용자 규칙 이름과 팝업 문구는 앱 언어와 무관하게 원문을 유지한다.

앱 사용법 버튼은 현재 앱 언어를 로컬 파일 URL의 `lang` 쿼리로 전달한다. 파일 경로에 공백·한글이 있어도 QUrl로 처리한다. 가이드에서 직접 선택한 언어는 브라우저 로컬 저장소가 허용되는 경우 기억한다. 직접 파일을 열면 마지막 선택을 사용하고 앱에서 열면 앱 언어가 우선이다. 저장소/URL 갱신이 제한된 브라우저에서도 현재 화면 전환은 동작한다.

본문과 사진 39장을 한 HTML에 포함하므로 번역 서버나 인터넷이 필요 없다. 기존 목차·접힌 상세 자동 열기·사진 확대/Esc를 유지하며, 전환할 때 상세의 펼침 상태를 유지한다. 열린 확대 사진은 언어 전환 시 닫는다.

`translations.json`은 표시 키별 한국어 원문, `translations.en.json`과 `translations.zh.json`은 번역이다. 공통 렌더러가 원문과 키를 대조하고 빈 번역·누락·불필요한 키·태그/링크/변수 손상·언어별 사진 누락을 배포 출력 생성 전에 차단한다. 변경된 한국어 문장은 번역과 함께 검토해야 한다. 공식 개정은 `2026-10-23.7`이다.

실제 CANoe/VN/차량의 새 취득 시험과 알려진 Diag 누락 원인 규명은 이 변경의 범위가 아니다. 기록·종료 동작을 바꾸지 않는다.

## 검증

소스 전체 698개 검사 통과(59.35초). 이후 배포 문서 검사에 다국어 본문·사진의 포함 검증을 추가해 해당 21개도 통과했다. Ruff, pip check, git diff --check 통과. 오프라인 Chromium에서 한국어·영어·중국어의 1100/360px 화면·링크·확대/Esc·마지막 선택 기억·앱 언어 우선까지 32개 화면을 확인했다. 가이드 사진은 언어별 현재 Qt 위젯 예시이며 실제 장비 시험이 아니다.

배포 ID는 `One Click Log-0.9.20_20261023_135033`, 소스는 변경 없는 `0e463d5a964c8bc3d1ad6fd52c3c8a32766a6071`이다. ZIP CRC/SHA256, EXE 버전/아이콘/의존 모듈과 문서 해시를 확인했다. 폴더·ZIP·추출본의 HTML/안내문은 바이트와 해시가 일치하며 미리보기와도 줄바꿈을 제외한 내용이 같다. ZIP 추출 EXE의 실제 앱 바이트코드로 관련 검사 353개가 통과했다(15.87초). 별도 실제 EXE의 중국어 프로필에서 사용법 로컬 HTML 열기와 `lang=zh` 전달, 모의 기록/정지·팝업·X 종료가 통과했다. 이 시험에서 실제 CANoe 측정/차량 취득은 하지 않았다.
