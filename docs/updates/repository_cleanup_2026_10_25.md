## 정리 내용

- AGENTS.md에 문서 분류·현재 기준과 과거 기록 구분·링크/생성물 검사 규칙을 추가했다.

- README·개발 안내·구조·요구사항·제어 정책·현재 상태·시험 PC·검증 계획/표를 현재 0.9.21 소스와 대조했다. 요구사항 ID 55개는 유지했다.
- 초기 계획·1~8단계·T-01~T-66 시나리오에는 과거 기록 표시와 현재 문서 링크를 넣었다. 실제 현장 실패·Diag 누락 분석과 해당 버전 근거는 보존했다.
- 공식 가이드로 통합된 위치 변경 안내와 더 이상 사용하는 화면이 아닌 HTML 시안을 삭제했다. 발표/성과 양식은 배포 가이드 밖으로 옮겼다.
- 앱 모듈의 참조와 기존 회귀 범위를 확인해 demo·worker 공통 요청·복구·이행·명시적 검증 경로를 유지했다. 제거된 화면의 미사용 번역 키 13종을 두 카탈로그에서 정리하고 진단 패키지의 옛 opt-in 설명을 바로잡았다.
- 실차 시험서 생성기를 tools로 옮기고 --check로 생성물 최신성을 검사한다. 경로 변경 전 2026-10-24.1의 같은 48 TC 결과 JSON도 새 문서에서 읽을 수 있게 했다. 저장/불러오기는 증빙 첨부와 별개다.
- tools/check_docs.py로 로컬 Markdown/HTML 링크와 문서 앵커를 검사한다. Git에서 제외하는 outputs 증거 링크는 별도로 집계하며 링크 검사 성공을 실제 증거 존재 확인으로 주장하지 않는다.
- 실제 버그리포트·TC 결과 JSON·진단 JSONL·사용자 DB·이력 아카이브에 대한 Git 제외 규칙을 보완했다. 기존 문서 4개의 개인 경로 7곳을 USERPROFILE 표기로 교체했다. 사용자 원본·기존 배포물·로컬 검증 산출물은 삭제하지 않았다.
- 가이드 개정은 2026-10-25.1이다. 이전 짧은 실사용 표본의 약 10~20분 진단 보관 환산과 현재 0.9.21 장시간 미실측 제한을 세 언어로 반영했다. SW 번호와 실제 장비 검증 범위는 유지한다.

- 전체 자동 검사: 728개 통과, 68.37초. 기본 unit/integration 범위이며 실제 장비 시험이 아니다.

- 검사 도구: 없는 링크·없는 앵커·직접 적은 개인 사용자 경로를 오류로 검출하는 임시 fixture 확인. 실제 원본/업무 자료는 사용하지 않았다.
