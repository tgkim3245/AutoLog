# 0.9.22 초기설정 BAT 통합과 Ethernet ZIP 저장

2026-10-25 · 사용자 가이드 2026-10-25.3

실차 PC의 CANoe 19 기본 자동 연결 등록과 Npcap 관리자 설치를 한 파일에서 진행하도록 Initial_Setup.bat를 배포 EXE 옆에 넣는다. 두 단계의 결과를 각각 표시하고 이미 존재하는 Npcap은 건너뛴다. CANoe 19 공식 도구의 버전·Vector 서명과 등록 결과, Npcap 고정 원본의 크기·SHA256·Nmap 서명을 확인한다. 관리자 요청과 공식 설치창은 사용자가 확인한다. --check에서는 두 도구를 실행하지 않는다. 빌드 정보와 ZIP에 BAT 이름·크기·해시를 기록한다. Npcap 설치기 자체는 기존과 같이 확인된 사내 PC 1대용 빌드에만 포함한다. [초기설정 절차](../guides/canoe_registration_helper.md).

설정 → Ethernet 연결 → 저장 방식에 원본 저장(기본)과 정지 후 ZIP 압축을 추가했다. 형식은 기존 pcap/pcapng를 유지한다. 기록 중에는 원본을 취득하고 정지·검사 후 ZIP64 지원 압축, 전체 해제 읽기·CRC/SHA256 대조, 압축본 식별 정보 DB 선저장, 덮어쓰기 없는 보관을 수행한다. 보관 확정 후 일치하는 원본만 정리한다. 최종 이름은 .pcap.zip/.pcapng.zip이며 내부에 원본 파일 하나가 있다. 압축 도중 두 파일을 둘 공간과 시간이 필요하다. 실패 시 원본을 보존하고 완료로 표시하지 않는다. X/강제 종료 중단 구간 폐기는 기존 정책을 따른다.

선택은 호환용 DB 확장 테이블에서 보존해 이전 v2 설정 문서를 읽는 릴리스와 분리했다. 미리보기·경로 길이·충돌·이름 변경·삭제·파일 식별·중단 작업·수동 보관도 ZIP을 처리한다. 세 언어 설명과 실제 Qt 위젯 사진을 다시 생성하고 TC-01/21에 초기설정 및 4조합(pcap/pcapng × 원본/ZIP)을 반영했다. 기존 48개 TC 제목·ID와 이전 결과 JSON 불러오기는 유지한다.

검증은 생성 자료와 임시 DB, Windows 실제 파일 핸들, 대체된 외부 도구를 사용한다. 설치/등록 취소·해시/서명/버전 오류·잘못된 COM 대상, ZIP 내용 일치·실패 시 원본 유지·기존 파일 보호·설정 유지·이름 변경/삭제·중단 후 처리를 확인한다. 실제 관리자 설치·COM 변경을 개발 PC에서 실행하거나 실차 기록 성공으로 표현하지 않는다. 실제 장비/차량과 고부하·장시간·대형 파일 시험은 현장 TC로 별도 수행한다.

자동 검증: 전체 770개 통과(75.75초), Ruff·pip check·426개 문서 링크·48 TC HTML 최신성·가이드 버전 검사 통과. 세 언어 Qt 사진 42장 재생성 및 HTML 1120px/390px 화면을 확인했다. 실제 설치/COM 변경·실차 취득은 이 검사에 포함하지 않는다.

## 배포물 확인

- 빌드: One Click Log-0.9.22-internal_20261025_101115. 소스 커밋 374a6e16f9d990adbe5eab79f108d0d38c84ef2c, clean 상태. 아래 검증 기록은 빌드 후 추가했다.
- 배포 ZIP: 270,167,302 bytes. SHA256: ef361894db9e51c2cdf3b56e58cd2a0208810746b622e9be9c158b8b42fff8ac.
- ZIP 전체 CRC, EXE 옆 초기설정 BAT와 가이드/START_HERE의 해시, 내부 Npcap 설치 파일 크기/해시가 build_info와 일치했다. BAT는 14,517 bytes이며 해시는 e45be74f68ec13caa6f0e2251106ce10c7a5bd57a726248df04a5930bee819c7이다.
- 동봉 Wireshark 4.6.9로 생성한 localhost UDP만 취득했다. pcap/pcapng × 원본/ZIP 4조합 각각 5패킷을 정상 정지·검사·보관했다. ZIP CRC/해제 내용 SHA256, 해제 파일 capinfos 전체 읽기와 실제 형식/건수, 재실행 후 ZIP 설정·4개 이력·다음 번호 5 유지도 통과했다. 물리 NIC는 열지 않았다.
- 배포 EXE 사본의 독립 프로필에서 offscreen smoke(시작·정지·종료, 오류 팝업, 진단 기본 저장)가 통과했다. BAT --check는 CANoe 19.3.118 공식 도구의 유효한 Vector 서명·현재 COM 대상 및 기존 Npcap 파일을 확인했고 설치/등록은 실행하지 않았다.
- 첫 EXE 시험의 Documents 경로 쓰기는 Controlled Folder Access 이벤트 1123으로 차단됐다. 다운로드 폴더의 분리된 사본/프로필에서 정상 실행했다. 보안 설정을 변경하지 않았다. 실차 PC의 허용 경로·권한과 실제 설치/등록·장비 기록은 별도 확인한다.

실제 경로·패킷·진단을 포함하는 검증 원본은 Git 제외 로컬 outputs/initial_setup_zip_20261025에 두고, 배포 원본에는 검증 중 생성된 진단·사용자 DB를 넣지 않았다.

## 초기설정 안내 노출과 CANoe 19 필수 조건 · 가이드 2026-10-25.5

접힌 상세에 있던 초기설정을 첫 화면의 펼쳐진 0단계와 상단 링크로 안내한다. CAN·Diag는 CANoe 19(64비트)를 사용해야 함을 준비 조건·도구 요구사항·등록 복구와 START_HERE에 명시했다. BAT의 관리자 요청·기본 COM 등록·Npcap 설치/건너뛰기·공식 설치창 조작·재부팅 후 재확인·기능별 결과 확인 순서를 세 언어에 반영했다. 프로그램·BAT 동작과 SW 버전은 유지하며 새 문서 개정과 빌드로 구분한다.
