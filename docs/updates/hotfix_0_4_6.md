# 0.4.6 — 새 PC 설치 안내와 실행환경 재확인

> 과거 기록: 이 문서는 작성 당시의 변경·검증 근거를 보존합니다. 현재 동작과 남은 확인 사항은 [현재 구현 상태](../reference/implementation_status.md)를 따릅니다.

2026-10-18 · AutoLog 0.4.6

## 동작

- 일반 앱 실행 시 선택 대상의 의존 도구를 백그라운드에서 확인한다. 미설치·실행 불가 또는 진단 실패가 있으면 환경 확인창을 자동으로 연다. 정상 환경은 자동 창으로 방해하지 않는다. 모의 실행에는 설치를 요구하지 않는다.
- Zipy/Ethernet은 TShark, dumpcap, capinfos와 Npcap을 확인한다. CAN/Diag를 선택하지 않으면 CANoe 부재를 필수 오류로 집계하지 않는다. CANoe 설치 발견은 라이선스·장비 또는 실제 CAN/Diag 기록 지원을 의미하지 않는다.
- 누락 항목의 ‘설치·복구 안내’에서 공식 설치 페이지를 열거나 PC에 준비한 `.exe`/`.msi` 설치파일을 선택해 Windows로 실행 요청을 보낸다. 실행 요청 성공을 설치 성공으로 판정하지 않는다. 설치 취소·열기 실패는 자동 준비 완료로 전환되지 않는다.
- ‘설치 후 다시 확인’은 TShark 경로와 네트워크를 새로 검색하고 환경 정보를 갱신한다. 저장된 이전 PC의 TShark 경로도 새로 찾은 정상 경로로 바꿀 수 있다. 관리자 권한 승인·설치 마무리는 Windows 설치창에서 진행한다. 드라이버 설치가 재부팅을 요구하면 재부팅해야 한다.
- 필수 도구가 미확인된 상태에서 logging을 누르면 세션을 시작하지 않고 환경 안내를 연다. 기록 중의 정지 버튼은 기존 정지 경로를 유지한다.
- 인터넷 없는 PC에서는 회사 승인 설치파일을 USB 등으로 준비해 ‘내 PC의 설치파일 실행’을 사용한다. EXE 배포본에는 Python과 Qt가 포함되며 외부 캡처 프로그램·드라이버는 별도로 설치한다.
- 개발자로그에 시작 시 누락 도구, 설치 페이지·로컬 설치파일 열기 결과, 재검색 결과를 남긴다.

## 공식 설치 자료

- [Wireshark 설치 안내](https://www.wireshark.org/docs/wsug_html_chunked/ChBuildInstallWinInstall.html): TShark 구성요소와 포함된 Npcap 설치 항목을 안내한다.
- [Npcap 다운로드](https://npcap.com/#download)
- [Vector CANoe](https://www.vector.com/en/product/canoe/): 회사에서 승인한 설치본·라이선스를 사용한다. 현재 실제 CAN/Diag 기록 연동은 개발 중이다.

## 검증

- 정적 검사와 자동 검사 221개 통과. 도구가 없는 시작과 정상 시작, 앱 실행 중 설치 완료를 모의한 재확인, 선택하지 않은 CANoe 제외, 보조 도구 실행 불가, 드라이버 확인 불가, 설치파일 선택 취소·열기 실패를 확인했다.
- 환경 확인창과 설치 안내창의 한국어 렌더링을 확인했다.
- 실제 새 PC에서 설치파일 다운로드·관리자 권한·설치/재부팅까지 진행한 검증과 차량 NIC·CANoe 현장 시험은 남아 있다. 파일 존재와 버전 조회만으로 실제 취득 성공을 표시하지 않는다.

## 배포본 확인

- 소스 커밋 `04aaae1`, 빌드명 `AutoLog-0.4.6_20261018_140936`. 미커밋 변경 없이 빌드했다. 이 PC의 결과 위치는 `Downloads/AutoLog_Builds/` 아래다.
- EXE의 제품명 AutoLog, 파일·제품 버전 0.4.6과 ZIP CRC·ZIP/EXE SHA-256 일치를 확인했다.
- ZIP을 별도로 풀고 개발용 Python 환경변수와 경로를 제외한 환경에서 EXE 모의 기록·정지·정상 종료를 확인했다. 종료 코드 0, 진단 55건과 필수 완료 이벤트를 확인했다.
- 상세 근거는 빌드 폴더의 `verification/result.json`에 있다. 이 검사는 Python이 실제로 없는 별도 PC의 설치·실행 시험을 대신하지 않는다.
