# One Click Log 1.0.0 릴리즈

2026-10-25 · 사용자 가이드 2026-10-25.7

SW 버전을 1.0.0으로 올리고 현재 기능·준비 조건·검증 범위를 검토했다. 설치 CANoe 검색/버전 선택과 기본 COM 등록, RBS 열기 실패 후 재설정, Npcap 준비, Ethernet 원본/정지 후 ZIP 보관, 파일 이력·정지/종료·버그리포트 동작을 유지한다. 버전 번호가 실제 RBS/장비/차량의 검증 범위를 확대하지는 않는다.

## Npcap 사용자 절차 정리

가이드 요구 도구·Ethernet·오류 조치와 START_HERE, 동봉 설치 안내에 남은 Npcap 별도 설치/설치기 수동 실행 안내를 수정했다. 기본 절차는 다음과 같다.

1. ZIP 전체를 로컬 폴더에 풀고 앱과 모든 CANoe 작업을 저장·종료한다.
2. EXE 옆 Initial_Setup.bat를 실행해 RBS 구성에 맞는 CANoe 설치본을 선택한다.
3. BAT가 Npcap 기설치 여부를 확인한다. 있으면 건너뛰고 없으면 동봉 설치기의 고정 해시/서명을 확인해 관리자 권한으로 자동 실행한다.
4. 사용자가 Windows 관리자 요청과 BAT가 연 공식 설치창의 라이선스·옵션·완료를 확인한다. 무인 설치는 아니다. 재부팅 요청 시 먼저 완료하고 BAT로 다시 확인한다.
5. 사용할 기능의 결과(CAN·Diag: CANoe: 0, Zipy: Npcap: 0)를 확인하고 앱을 실행한다.

설치 파일 누락은 전체 ZIP 해제·배포 범위를 확인하는 예외 조치로 분리했다. Npcap 설치기는 확인된 같은 회사 내부 PC 1대용 빌드에 포함하고, 일반 빌드에는 포함하지 않는 기존 범위를 유지한다. 설치 파일/실제 캡처/진단은 Git에 넣지 않는다. 앱의 Npcap 누락 안내도 BAT 실행으로 통일했다.

## 배포와 검증

세 언어 가이드·START_HERE·현재 문서/실차 시험서의 참조 버전을 갱신하고 Qt 사진 42장을 1.0.0으로 재생성한다. 48 TC 제목/ID 및 이전 결과 JSON 불러오기를 유지한다. 배포에는 앱/도구/라이선스/초기설정 BAT/가이드/해시 정보가 포함된다.

자동 검사와 생성 자료·읽기 전용 검색·분리된 프로필의 배포 EXE 실행을 실제 관리자 설치/COM 변경·RBS 호환·실차 취득 성공과 구분한다. 실제 장비·부하·장시간·알려진 Diag 누락 확인은 [실차 TC](../testing/vehicle_test_plan.md)와 [환경별 실제 근거](../testing/canoe_support_matrix.md)를 따른다.

검증: 전체 자동 검사 784개 통과(79.90초), 최종 가이드 검사 40개 통과, Ruff/pip check/435개 문서 링크/48 TC HTML 최신성 검사 통과. 세 언어 Qt 사진 42장과 데스크톱/390px Npcap 자동 설치 안내·오류 조치·재설정 링크를 확인했다. 배포 실행/무결성 확인 후 v1.0.0 태그로 해당 소스를 지정한다. 실제 관리자 설치/COM 변경·실차 취득은 이 자동 검증에 포함하지 않는다.
