# 검증 계획

기준 SW 0.9.23 · 검토 2026-10-25

자동 검사, 명시적 localhost 검사, 실제 장비/차량 시험을 구분한다. 현재 수동 실차 절차는 [48 TC 시험서](vehicle_test_plan.md)와 [결과 입력 HTML](One_Click_Log_Vehicle_Test_Plan.html)이다. 모든 TC의 초기 결과는 미실행이다. 결과는 [텍스트 양식](vehicle_test_result_template.md) 또는 HTML의 JSON으로 별도 보관한다.

## 검증 단계

| 단계 | 실행 범위 | 성공으로 주장할 수 있는 범위 |
| --- | --- | --- |
| 기본 pytest | unit·integration의 생성 자료·COM 대역·테스트 프로세스 | 검사한 제어/파일/화면 경로. 차량 수신·라이선스 실증 아님 |
| 정적/의존성 | Ruff·pip check·문서 링크·생성물 최신성 | 소스/설치 메타데이터/문서 일관성 |
| 명시적 CLI | --verify-ethernet/monitoring/recovery/load/file-management | 지정 localhost·생성 파일·도구 조합. 물리 NIC 성능 아님 |
| 시험 PC 준비 | cfg·라이선스·매핑·NIC·실제 원본 읽기 | 해당 PC/도구/장비 조합의 확인한 범위 |
| 실차 48 TC | 정상·조합·반복·누락·이상·종료·장시간 | TC별 실제 증빙과 판정. 미실행/Blocked를 통과로 올리지 않음 |

장비 없는 기본 검사는 `pyproject.toml`의 tests/unit·tests/integration을 따른다. `tests/hardware/verify_ethernet_ui.py`는 명시적 localhost UI 경로이며 물리 차량 시험을 자동 수행하지 않는다. 실행 명령과 환경 준비는 [개발 안내](../../CONTRIBUTING.md)에 있다.

## 실차 범위

| TC | 범위 | 중점 |
| --- | --- | --- |
| 01~08 | 배포·준비·독립 cfg·F9·NIC·설정 유지 | 실제 대상 대응·기존 기록/설정 보호 |
| 09~15 | 7가지 선택 조합 | 선택 파일만 생성·실제 내용 읽기·번호 공유 |
| 16~18 | 10회 반복·짧은 구간·선택/prefix 전환 | 측정 유지·번호·두 번째 시작·중복 클릭 |
| 19~22 | 진단 왕복·CAN/Diag 누락·형식·Source | 파일 보관과 데이터 완전성 별도 판정 |
| 23~31 | 수신/링크/도구 이상 | 전체 정지·비모달 알림·새 구간 재시도·CAN 감지 한계 |
| 32~36 | 이름·삭제·충돌·접근/보관 실패 | 덮어쓰기 금지·실제 경로·부분 결과 |
| 37~40 | 정상 종료·X·강제 종료·재실행 | 완료/번호 보존·미완료 폐기·무관한 프로그램 보호 |
| 41~42 | 60분·1 GiB 초과·저용량/쓰기 실패 | 시간/용량 개별 확인·원본과 진단 오류 구분 |
| 43~48 | ZIP·회전·재실행·오프라인·주행 | 오류 직후 증빙·고정 스냅샷·실행 폴더 분리 |

이상 조작은 TC의 정차/격리 환경을 지키며 실제 차량 제어선·전원·공용망을 임의 조작하지 않는다. 주행 중 오류 주입·강제 종료를 수행하지 않는다.

## 판정과 회귀

Pass는 해당 TC가 요구하는 UI/파일/내용 증거 확인 후 기록한다. 파일 구조 유효·0프레임·completed는 정상 통신/무손실 보장이 아니다. CAN/Diag가 서로 다른 버스면 단순 누락 비교를 하지 않는다. 동일 버스의 시간차·경계·방향 차이를 통제하거나 독립 기준을 준비한다.

수정 후 해당 실패 TC와 영향받는 TC-15·16·20·37을 재시험한다. 데이터 손실·덮어쓰기·무관한 프로세스 종료는 최우선 결함으로 남긴다. 결과에는 실제 버전/빌드·회차·시간대·재현율·ZIP·원본·복구 내용을 포함한다. [환경별 검증표](canoe_support_matrix.md)에는 실제 확인 사실만 추가한다.

과거 T-01~T-66 시나리오와 초기 자동 검사 숫자는 [초기 검증 시나리오 기록](../archive/planning/validation_scenarios_0_8_5.md)에 보존한다. 제거된 패킷 보기/환경 창·이전 종료 정책의 기대 결과를 현재 시험에 재사용하지 않는다.
