# One Click Log 실차 시험 결과 기록

기준 시험서 2026-10-25.1 · 기준 SW 1.0.0

회차별 복사해 사용한다. 실측 결과·차량 로그·cfg·개인 경로는 Git 밖의 승인된 자료 폴더에 보관한다. HTML 시험서에서도 입력해 JSON으로 저장할 수 있다.

## 시험 환경

- 시험 회차 ID와 시험자:
- 시험일과 시간대:
- 실제 EXE 버전과 빌드 ID 및 ZIP/EXE SHA256:
- PC 별칭과 Windows 빌드:
- 차량 별칭과 ECU SW 버전:
- CANoe 버전과 옵션 및 Vector 드라이버/장비 별칭:
- CAN cfg 별칭과 BLF 블록 및 채널 매핑:
- Diag cfg 별칭과 BLF 블록 및 채널 매핑:
- 동일 버스 비교 가능 여부와 근거 및 DBC 버전:
- NIC 이름과 안정 식별자 및 포트:
- TShark와 Npcap 버전:
- 실제 Zipy 규칙과 시간 및 최소 pps:
- 저장 위치 별칭과 prefix 및 최초 번호:
- 초기 디스크 여유와 예상 기록량:
- 환경과 승인된 시험 시나리오:

## TC별 결과

TC-01~48 중 수행한 항목마다 아래 블록을 복사한다. 상태는 Not Run / Pass / Fail / Blocked / N/A 중 선택한다. 재시험은 회차별 별도 기록을 남긴다.

- TC ID와 제목 및 회차:
- 상태:
- 시작과 종료 시각 및 시간대:
- 이상 발생 시각:
- 선택 대상과 prefix 및 예약 번호:
- 사전조건과 실제 누른 순서:
- 기대 결과:
- 실제 결과와 측정값:
- 파일별 이름/크기와 reader 검사:
- 첫/끝 프레임 시각과 프레임 수:
- 버그리포트 ZIP 이름과 생성 시각:
- 화면/Write 증빙 이름:
- 결함 ID 또는 Blocked/N/A 사유:
- 복구와 다음 시험 가능 여부:

- TC와 회차 및 중요도:

- 실제 버전과 빌드 ID:
- 발생 시각과 시간대:
- 재현 시도 횟수와 실패 횟수 및 순서:
- 기대와 실제 결과 및 오류 원문:
- 선택 대상과 cfg 별칭 및 번호:
- 종료 전 ZIP과 재실행 후 ZIP:
- 관련 BLF/PCAP/화면 증빙:
- 손실과 영향 범위:
- 임시 복구와 결과:
- 원인 상태: 미확정 / 환경 원인 확인 / 프로그램 원인 확인
- 재시험 버전과 결과:
