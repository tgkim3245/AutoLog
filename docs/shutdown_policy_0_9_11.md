# AutoLog 0.9.11 — X 완전 종료·중단 구간 폐기

2026-10-22. 사용자는 X로 중간에 끝낸 기록의 임시 파일 보존을 원하지 않으며, AutoLog가 연 CANoe 두 창도 함께 종료하도록 명시했다. 기존 정상 기록 정지/보관과 별도의 종료 정책이다. 기존 cfg와 실제 측정은 이 작업에서 조작하지 않았다.

## 이번 현장 근거

ZIP CRC와 manifest 크기/해시가 일치했다. JSONL 1,731건·3,046,180바이트·SHA256 `b2bd5320a3d90a0ca12da5c5bad69b41318afe9e66cab04c96c05e4a1130ac3b`다. 0.9.10의 네 구간은 정상 보관했고 다섯 번째 구간은 시작/조회까지 성공했다. 마지막 로그는 패킷 보기 1,000건을 여는 동작이다. Windows AppHangB1/1002도 뒤따랐다. 구체적인 native stack은 없어 호출 위치의 확정은 구분한다.

재실행 5회 모두 같은 13번의 DB 미완료 이력으로 차단됐다. 사용자가 작업 폴더를 삭제해 세 파일이 없어도 DB 상태는 남아 있었다. 이력 차단은 폴더 삭제로 풀리지 않는 기존 정책이었다. 그 5회 중 X 요청이 기록된 실행들은 정상 종료 결과를 반환했다. 이번 근거를 모든 X가 트레이로 숨겼다고 해석하지 않는다.

## 구현

- 시작 시 이전 중단 구간을 failed/폐기로 정리하고 대기 상태로 진입한다. 다음 번호를 유지하며 수동 복구를 요구하지 않는다. 폐기 의도 기록 후 알려진 작업 파일을 독점 핸들로 삭제한다. UUID 작업 디렉터리·최종 폴더 관계와 일반 파일/링크 여부를 검증하며 완료 파일·외부 경로·알 수 없는 폴더 내용은 삭제하지 않는다. 잠긴 소유 파일은 pending으로 재시도하지만 새 기록을 막지 않는다.
- X는 현재 기록을 정상 보관하지 않는다. AutoLog worker·dumpcap job을 종료하고 이번 실행의 CANoe까지 닫는다. CANoe 생성 progress에서 PID를 받아 실행 파일명·생성 시간을 확인한 뒤 프로세스 핸들을 보유한다. 종료는 그 핸들만 사용하므로 PID 재사용이나 다른 CANoe 창을 프로세스명으로 일괄 종료하지 않는다. 원래 cfg는 저장하지 않는다.
- 종료 제한은 약 1초이며 반복 X는 즉시 강제 종료한다. 트레이 아이콘을 제거하고 종료 요청 시 모든 AutoLog 창을 닫는다. 남은 진단/파일 처리가 종료를 계속 지연시키지 않게 기존 독립 guard를 유지한다. 강제 종료 때 DB 정리가 못 끝나도 다음 실행에서 같은 폐기를 수행한다.
- 패킷 보기의 QTableWidget 5,000셀 생성/반복 변경을 QAbstractTableModel/QTableView의 한 번 갱신으로 바꿨다. 내용 기준 자동 열 너비 측정을 제거하고 보이는 셀만 그린다. 1,000건 제한·필터·일시 정지·원본 기록 분리를 유지한다.
- 완료 파일 이름 변경의 Enter 지원은 유지한다. 종료와 재실행 정책을 한·영·중 안내 및 가이드에 반영했다. 채널 매핑 등 사용자 cfg 변경은 기록 전에 직접 저장해야 한다.

## 현재 PC 정리

AutoLog/dumpcap/TShark가 실행 중이지 않은 것을 확인하고 SQLite를 사전 백업했다. 사용자가 이미 삭제한 13번의 파일은 다시 만들거나 복구하지 않고 DB 이력만 폐기로 정리했다. 완료된 파일과 다음 번호 14는 유지했다. 로컬 근거는 빌드 저장소 `policy-update-0.9.11/`에 보관하며 DB·개인 경로는 Git에 넣지 않는다.

## 검증 범위

폴더가 남음/없음·잠김 재시도·잘못된 경로·이미 보관된 부분 결과와 외부 파일 보호, 재실행 대기·번호 유지, 실제 Qt X/중단 폐기/완료 보존, 초기화·진단 정체 중 프로세스 종료를 검사한다. 실제 Windows 테스트 프로세스 핸들 종료와 무관한 프로세스 유지, 비-CANoe 프로세스 등록 거부를 검사한다. 1,000건 패킷 창 반복 표시/닫기와 메인 X도 검사한다. 실제 CANoe 창의 종료/장비 재연결과 차량 고부하·장시간 검증은 새 버전 현장 재시험으로 남아 있다.

전체 자동 검사 584개(56.23초), Ruff·의존성·diff·문서 링크 290개를 통과했다. 공식 가이드 개정 2026-10-22.3의 12개 PC/작은 폭 뷰포트에서 내용과 배치를 확인했다. 렌더링 근거는 로컬 빌드 저장소 `user-guide-2026-10-22.3/visual-qa/`에 보관한다.
