# 사용자 가이드 사진 안내 — 2026-10-24.1

적용 SW: One Click Log 0.9.21. 기록·연결·종료 동작은 변경하지 않았다.

## 변경

- 한국어·영어·중국어 각 14장, 총 42장에 빨간 대상 테두리·번호·화살표를 표시한다.
- 각 사진의 번호 순서대로 조작한다. 클릭은 `Click`, 입력·선택·결과 확인은 별도 문구로 구분한다.
- 사진 옆에 짧은 설명을 두어 원래 버튼 글자를 가리지 않는다. 사진을 누르면 안내 표시까지 함께 확대된다.
- 버그리포트는 메인 버튼 위치와 바탕화면 ZIP 저장 결과를 각각 보여 준다.
- 화면은 실제 Qt 위젯을 설명용 상태로 촬영했다. 실제 cfg·취득 파일·개인 경로를 사용하지 않았다. PNG를 변형하지 않고 HTML의 SVG로 표시한다.
- 재촬영 시 실제 위젯 좌표와 PNG 해시를 함께 저장한다. 배포 렌더러는 버전·사진·번역·좌표·순서 누락 및 불일치를 차단한다.

## 확인

- 가이드·배포 문서·Npcap 패키징 관련 단위 검사 51개 통과. 수정 Python 파일 Ruff와 `git diff --check` 통과.
- 오프라인 Chromium에서 세 언어 × 데스크톱 1100px·작은 화면 360px 등 68개 화면 검사 통과. 언어 전환·기억·앱 언어 우선·이미지 로드·접힌 상세 링크·확대/Esc·페이지 넘침을 확인했다.
- 별도 브라우저 검사에서 42장 모두 화살표 수와 조작 순서 수 일치, 사진 크기·이미지 로드, 안내 글자 영역 내 표시, 접근성 설명을 확인했다. 세 언어 모두 확대 시 표시 유지와 작은 화면의 가로 스크롤을 확인했다.
- 저장 설정·CAN 연결·완료 파일·중국어 확대 화면을 직접 확인했다.

실제 CANoe 측정·장비/차량 취득·Npcap 설치를 이번 문서 작업에서 실행하지 않았다. 기존 가이드의 실제 검증 범위와 알려진 Diag 누락 제한을 유지한다.
