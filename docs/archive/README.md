## 정리한 중복 자료

2026-10-25에 과거 HTML 화면 시안 `docs/design/wireframe.html`과 공식 가이드로의 위치 변경만 알리던 `user_guide/user_guide_draft.md`를 삭제했다. 현재 Qt 화면·실제 사용법 사진·공식 가이드가 대체한다. 이전 내용은 Git 이력에서 찾을 수 있다. 초기 계획의 삭제된 시안 언급은 당시 계획의 맥락이며 재실행 가능한 현재 UI가 아니다.

이력 문서는 사실을 덮어쓰지 않고 위 현재 문서로 연결한다. 상세 로컬 증거·개인 경로·원본 cfg는 Git에 포함하지 않는다.
