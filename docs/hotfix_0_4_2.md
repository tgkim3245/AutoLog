# 0.4.2 — 임시 폴더 정리와 개발자 로그 표시

2026-10-18 · VIL Logging 0.4.2

[실행 파일](../outputs/hotfix-0.4.2/VILLogging/VILLogging.exe). 실행 폴더의 `_internal` 디렉터리도 함께 유지한다.

## 변경 사항

- 캡처 파일을 최종 저장 위치에 보관한 뒤 비어 있는 `.vil_work/<세션>` 폴더를 제거한다. 세션 임시 폴더에 미완료 캡처가 남아 있으면 복구를 위해 보존한다. 다른 세션 작업이 없을 때만 공용 `.vil_work` 폴더도 제거한다.
- 개발자로그는 체크를 켤 때 JSONL 파일 하나를 만들고 체크가 켜진 동안 같은 파일에 앱과 캡처 동작 기록을 추가한다. 캡처 버튼을 누를 때마다 새 파일을 만드는 방식은 아니다. 메인 화면 상태 줄에 현재 파일명을 표시하고, `로그 폴더` 버튼으로 저장 위치를 연다. 체크를 껐다가 다시 켜면 새 파일을 만든다.

## 검증

- 자동 테스트 203개 통과, Ruff 통과.
- 배포 EXE 모의 실행 통과. 개발자로그 1개에 녹화 시작·완료를 포함한 60개 기록이 저장됐다.
- 실제 차량 NIC, CANoe 캡처, 고속·장시간 수집은 검증 범위에 포함하지 않았다.
