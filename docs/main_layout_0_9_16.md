# 메인 파일·최근 활동 배치 — 0.9.16

2026-10-23. 파일 영역의 제목·작업 이력·직전 로그 지우기를 하나의 가로 행으로 합쳤다. 작업 이력은 삭제 버튼 바로 왼쪽이다. 상단 로깅 대상 줄의 로그 폴더와 파일 이름 변경/삭제 동작은 유지한다.

최근 활동 목록은 120px로 고정해 일반 한 줄 항목 약 4~5줄을 보여준다. 창이 커져도 목록을 늘리지 않는다. 기본 창은 480×660으로 줄이고 작은 화면에서는 기존 전체 창 스크롤을 유지한다. 항목이 길어 줄바꿈하면 보이는 항목 수는 줄어들 수 있다.

활동 헤더의 복사 버튼과 건수 표시는 삭제했다. 복사 핸들러·선택 연결·사용하지 않는 번역도 제거했다. 최근 500건 보관, 전체/경고·오류/오류 필터, 목록 스크롤과 원문/상세 툴팁은 유지한다. 개발자 로그·버그리포트는 바뀌지 않는다. CAN·Diag·Zipy의 취득/감시/종료 동작도 바꾸지 않는다.

화면 배치와 기존 활동 필터/500건/상세 보존 검사를 갱신했다. 최종 검증 결과는 배포 빌드 후 기록한다.
